# v1.0.8 — 久坐提醒「跑道小人」

DSH 久坐提醒插件：顶部居中的**环形操场跑道** HUD，小人沿跑道跑完一轮久坐（默认 15 分钟）；连续坐满 30 分钟弹窗 + 桌面通知 + 提示音喊你站起来；离开自动暂停、回来智能恢复；每天一份久坐报告。

npm 同版本：[`dsh-sitmax@1.0.8`](https://www.npmjs.com/package/dsh-sitmax)

---

## ✨ 它是什么样的

- **跑道 HUD**：沙金小字显示已坐时间与状态；平时收起为 30px 小进度环不挡界面，悬停展开完整跑道；可拖动、位置记忆、双击复位
- **站立提醒**：休息 5 分钟 / 暂缓 5 分钟二选一，附桌面系统通知与提示音
- **真·离开检测**：Windows 默认系统级空闲检测（`GetLastInputInfo`）——切到别的软件/标签页都算在工作，整个系统无输入才判离开；其他平台回退页面内检测
- **下班 / 加班**：点月亮下班清零已坐时长，点公文包加班从头计时
- **每日报告**：今日久坐时长、提醒/休息/轮次次数、近 7 天柱状图、按月日历与事件时间线
- **设置页**：循环 / 提醒 / 休息 / 暂缓 / 离开判定 / 上班时间等全部可调，存浏览器本地

## 📦 安装

```powershell
dsh plugin --profile web add dsh-sitmax@1.0.8
```

要求 DSH `>= 0.2.2-0 < 0.3.0`。纯客户端插件：安装后**刷新页面**即生效，无需重启宿主。
