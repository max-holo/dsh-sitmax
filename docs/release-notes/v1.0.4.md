# v1.0.4 — 久坐提醒「跑道小人」

久坐提醒插件：跑道环形 HUD 实时显示已坐时长，到点提醒你站起来，离开自动暂停，每天一份久坐报告。

本仓库首个公开 Release。npm 已发布同版本：[`dsh-sitmax@1.0.4`](https://www.npmjs.com/package/dsh-sitmax)。

---

## ✨ 它是什么样的

- **顶部居中的环形操场跑道**：一个小人沿跑道跑动——跑完一圈就是一轮久坐（默认 15 分钟），跑道中心的沙金小字显示已坐时间与当前状态
- **连续坐 30 分钟**弹出「该起来走走了」卡片：休息 5 分钟 / 暂缓 5 分钟二选一，附桌面系统通知 + 提示音
- **知道你真的离开了**：键鼠无操作自动暂停，回来智能恢复；离开超过休息时长则自动按一次休息重置。Windows 上默认用**系统级空闲检测**（`GetLastInputInfo`）——切到别的软件、别的标签页都算在工作，只有整个系统无输入才判定离开（其他平台回退为页面内检测）
- **下班 / 加班**：点月亮下班，已坐时长清零；点公文包加班，新一轮从头计
- **每日报告**：今天久坐时长、提醒/休息/轮次次数，近 7 天柱状图

## 🖱 交互

- 平时只显示 30px 的小进度环（不挡界面），**悬停展开**完整跑道 + 时间 + 按钮
- **可拖动**到任意位置，位置自动记住（localStorage），**双击复位**
- 点跑道：手动暂停 / 继续

## ⚙️ 设置

设置 → 「久坐提醒 · 设置 / 报告」：循环 / 提醒 / 休息 / 暂缓 / 离开判定时长与各项开关，全部持久化在浏览器本地（`dsh.sitmax.*`），跨会话累计；桌面通知首次使用需授权。

纯客户端插件：安装后**刷新页面**即生效，无需重启宿主。

---

## 📦 安装 / 升级

```powershell
# DSH 插件页 → 发现 → 搜索 dsh-sitmax → 安装；或命令行：
dsh plugin --profile web add dsh-sitmax@1.0.4
```

要求 DSH `>= 0.2.2-0 < 0.3.0`。
